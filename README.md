# Mitsubishi PLC Demo Kit

Industrial automation demo kit based on Mitsubishi Electric iQ-R PLC platform.

---

## Overview

This repository contains the PLC, HMI, inverter, motion control, CC-Link, and IO-Link projects used for learning, testing, and industrial demonstrations.

Main features:

- PLC Programming (GX Works3)
- HMI (GT Designer3)
- CC-Link IE Field Network
- CC-Link V2
- Remote I/O
- Mitsubishi Inverter
- Balluff IO-Link Master
- Analog I/O
- Motion Control
- Industrial Communication

---

# Hardware

## PLC

| Module | Description |
|---------|-------------|
| R61P | Power Supply |
| R01CPU | CPU |
| RX40C4 | Digital Input |
| RY41NT2P | Digital Output |
| R60AD4 | Analog Input |
| R60DA4 | Analog Output |
| RD77MS4 | Motion Module |
| RJ61BT11 | CC-Link Master |
| RJ71C24 | Serial Communication |
| RJ71GF11-T2 | CC-Link IE Field Network |

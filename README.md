# Demo Kit Mitsubishi Automation

Demo Kit untuk pembelajaran dan pengembangan sistem otomasi industri berbasis Mitsubishi Electric.

## Hardware

- Mitsubishi MELSEC iQ-R R01 CPU
- Mitsubishi GOT2000 GT2708-VTBA
- Mitsubishi Remote I/O
- Balluff IO-Link Master
- Balluff IO-Link Devices

## Software

- GX Works3
- GT Designer3
- FR Configurator2 (jika digunakan)

## Repository Structure

```
PLC/
HMI/
Remote-IO/
Balluff/
Documents/
Wiring/
Images/
```

## Features

- PLC Program (GX Works3)
- HMI Project (GOT2000)
- Remote I/O Configuration
- Balluff IO-Link Configuration
- Documentation
- Wiring Diagram
